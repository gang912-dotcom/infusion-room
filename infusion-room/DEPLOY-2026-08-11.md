## 3. 기동 로그 확인 — 여기가 이번 배포의 핵심

로그는 `C:\iv-app\logs` 에 있다. 서버가 뜨면서 아래 **5줄**이 찍혀야 한다.

```
[db] 미량원소 → 멀티 5주 통합: 항목 1개 삭제, 기록지 스냅샷 N건 정정
[db] 묶음 200-2(부신기능저하증) 추가: 항목 13개
[db] 묶음 2번·3번 EMR 정정: 2번 B6 1→3 · 2번 B5 1→제거 · 2번 데노간 1→2 · 3번 데노간 1→2
[db] 수액실 '기타' 베드 10개 추가
[db] 통계 화면 암호 초기값(8058) 설정
```

**`N`(기록지 스냅샷 정정 건수)을 사용자에게 반드시 보고할 것.** 종료된 세션의 얼린
기록지를 고친 유일한 항목이라 숫자를 남겨 둬야 한다.

5줄이 다 안 보이면 멈추고 로그 원문을 사용자에게 보여줄 것.

## 5. 통계 암호 바꾸기 — **사용자가 직접**

초기 암호 `8058`이 **공개 GitHub 레포에 그대로 적혀 있다.** 배포 직후 바꿔야 한다.

앱에서 `데이터관리 → 관리자 설정 → 통계 화면 암호`.
두 칸에 같은 값을 넣어야 저장된다.

> Claude Code는 비밀번호를 대신 입력하지 않는다. 사용자에게 안내만 할 것.

## 6. 더미 환자 정리 — **목록을 사용자가 확인한 뒤에만**

시험 삼아 등록했다 취소한 환자(예: `113143124 이강희`)가 환자 검색에 남아 있다.

앱에서 `데이터관리 → 관리자 설정 → 더미 환자 정리`.

- 후보가 이름·차트번호·등록시각과 함께 뜬다
- **사용자가 목록을 눈으로 확인**하고, 모르는 이름이 섞여 있으면 **지우지 말 것**
- `선택한 N명 지우기` → 되돌릴 수 없다는 확인이 한 번 더 뜬다

판정 기준(참고): 앱에서 등록하며 만들어진 환자(생성 시각 = 첫 배정 시각)이면서,
유효한 방문이 0건이고, 기록(라운딩·증상·바이탈·처방·노트)이 하나도 없는 경우만.
**EMR에서 일괄 임포트한 환자는 절대 안 걸린다.**

기록이 붙어 있어 못 지우는 환자는 이유와 함께 따로 보여준다.

## 7. 근무 PC에 앱 바로가기 (여러 대)

크롬의 정식 '설치' 버튼은 HTTPS에서만 뜬다. 원내 서버는 `http://192.168.0.86:4000`이라
**PC에서는 설치 버튼이 안 뜬다.** 대신 `--app=` 바로가기를 만든다(결과는 같다 —
주소창·탭 없는 독립 창, 작업표시줄 아이콘, Alt+Tab 독립 항목).

배포하면 아래 두 파일이 생긴다:

```
C:\iv-app\infusion-room\setup-pc-app.bat
C:\iv-app\infusion-room\setup-pc-app.ps1
```

**두 파일을 같은 폴더에 함께** USB나 공유폴더로 각 PC에 복사 → `setup-pc-app.bat` 더블클릭.

- 크롬을 세 경로에서 찾고, 없으면 엣지로 떨어진다
- 아이콘을 서버에서 받아 `%LOCALAPPDATA%\infusion-room\`에 둔다
- 바탕화면에 `수액실 관리` 바로가기 생성
- **작업표시줄 고정은 손으로** (윈도10부터 스크립트로 막혀 있다)

> 이 스크립트는 윈도에서 **한 번도 실행해 본 적이 없다.** PC 한 대에서 먼저 돌려 보고,
> 실패하면 화면 문구를 사용자에게 받아 고칠 것.

**아이패드**는 사파리 → 공유 → `홈 화면에 추가`. (여기는 HTTPS를 안 따진다)

## 8. 눈으로 확인할 것

앱을 열고(가능하면 새로 만든 바로가기로):

| 확인 | 기대 |
|---|---|
| 탭 줄 | `기타` 탭이 생겼다 |
| 전체 탭 | `기타` 섹션이 **안 보인다**(아무도 없을 때). `빈 베드` 수에 기타 10칸이 안 더해졌다 |
| `기타` 탭 | 베드 10칸이 보이고 배정이 된다 |
| 통계 탭 | 암호 창이 뜨고, 뒤에 통계가 안 보인다. `돌아가기`·`확인` 버튼 크기가 같다 |
| 통계 화면 | `진료실별 이용건수` 카드가 있다 |
| 처방 작성 | 묶음 줄에 `200-2`가 있다(`200-10`과 `200-202` 사이) |
| 처방 작성 | `110-101` 묶음을 누르면 **비타민D 경고창**이 뜨고, 목록에서 비타D가 **빨갛다** |
| 좌상단 로고 | 누르면 새로고침된다 |
| 데이터관리 | `증상 데이터 관리`의 검색칸 아래 빈 공간이 없다 |
| **수액간호기록지 인쇄** | 처방이 **2단**으로 나오고, 서명이 문서 맨 아래 `확인` 줄에 있다 |

기록지는 **실제로 한 장 뽑아 보라고 사용자에게 권할 것.** 종이로 쓰는 문서라 화면만으로는
확정할 수 없고, 어제 레이아웃을 크게 바꿨다.

## 9. 잘못되면

**되돌리기**는 백업 복원뿐이다. 마이그레이션은 `settings` 플래그로 1회만 돌아서
재기동으로는 안 되돌아간다.

```bat
REM 서비스 정지 → DB 교체 → 시작. 사용자 확인을 받고 진행할 것.
REM 서비스 이름은 iv-app이다. nssm은 PATH에 없을 수 있어 전체 경로로 부른다.
"C:\iv-app\tools\nssm.exe" stop iv-app
copy /Y D:\iv-backup\<백업파일>.db C:\iv-app\infusion-room\server\data\infusion.db
"C:\iv-app\tools\nssm.exe" start iv-app
```

코드만 되돌리려면 `git checkout 0e76bb9` 후 재기동(DB는 그대로 남는다 — 앱이 옛 코드로
새 DB를 읽게 되니 권장하지 않는다).
