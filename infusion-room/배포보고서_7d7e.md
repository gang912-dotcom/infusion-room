## 4. 작업지시서와 달라진 점 (중요 — 실제 코드/환경에 맞춰 수정)

1. **경로**: 지시서의 `infusion-room\infusion-room`(이중 중첩)은 틀림 → 실제는 `C:\iv-app\infusion-room` 한 단계.
2. **시드 명령**: `npm run seed` → 실제 스크립트는 **`npm run db:seed`**.
3. **`.env` 미사용**: 코드에 dotenv·`--env-file`이 없어 `.env`를 읽지 않음. 그래서 서버 디스크에 비밀번호 평문파일을 남기지 않고, admin 초기비번은 **시드 시 일회성 환경변수**로만 전달. PORT는 기본 4000.
4. **pm2 → nssm**: 사용자 결정에 따라 pm2 대신 nssm으로 node 직접 등록(윈도우에서 더 안정적). 이에 따라 pm2-logrotate 대신 **nssm 내장 로그 로테이션** 사용, `deploy.bat`도 `nssm restart` 기반.
5. **better-sqlite3**: npm11이 네이티브 빌드 스크립트를 차단한다는 경고가 떴으나, v12는 prebuilt 바이너리를 포함해 `require` 정상 → 문제 없음.
6. **배치 인코딩**: `.bat`은 cmd 코드페이지(949) 기준이라 서비스·규칙·작업 이름을 모두 ASCII로 통일(`iv-app`, `IVApp-Port4000`, `IVApp-DB-Backup`).
7. **nssm start 버그 회피**: `nssm start`가 START_PENDING에서 실패코드를 반환 → `admin-setup.bat`이 `sc query`로 RUNNING을 폴링하도록 수정.
