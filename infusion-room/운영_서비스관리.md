# 수액실 앱 — 서버 서비스 운영 안내 (7e)

## 채택 방식
- **nssm이 `node server/index.js`를 윈도우 서비스로 직접 실행한다** (pm2 사용 안 함).
- 서비스 이름: **`iv-app`** / 표시 이름: `Infusion-room server (iv-app / suaeksil)`
- 부팅 시 자동 시작(`SERVICE_AUTO_START`), 프로세스가 죽으면 nssm이 자동 재시작(3초 지연).
- 실행 파일: `C:\Program Files\nodejs\node.exe`  작업폴더: `C:\iv-app\infusion-room`  포트: 4000

## 로그 & 로테이션 (pm2-logrotate 대체)
pm2를 안 쓰므로 pm2-logrotate 대신 **nssm 내장 로테이션**을 사용한다.
- 표준출력 → `C:\iv-app\logs\out.log`, 표준에러 → `C:\iv-app\logs\err.log`
- **10MB를 넘으면 자동 회전**(`AppRotateBytes=10485760`, 실행 중에도 회전).
- 회전되어 쌓인 옛 로그는 `backup.bat`(매일 실행)이 **7일 지난 것 자동 삭제** → "retain 7"과 동일 효과.

## 최초 설치 (관리자 1회)
`admin-setup.bat` 을 **우클릭 → 관리자 권한으로 실행**. 방화벽 4000 + 서비스 등록 + 백업 스케줄이 한 번에 된다.

## 서비스 조작 (관리자 권한 명령프롬프트)
nssm은 PATH에 없으므로 전체 경로로 부른다.
```
"C:\iv-app\tools\nssm.exe" start iv-app       REM 시작
"C:\iv-app\tools\nssm.exe" stop iv-app        REM 정지
"C:\iv-app\tools\nssm.exe" restart iv-app     REM 재시작
"C:\iv-app\tools\nssm.exe" edit iv-app        REM 설정 GUI 열기
sc query iv-app                               REM 상태 확인(관리자 아니어도 됨)
```
- 서비스 목록 GUI: `services.msc` → "Infusion-room server" 항목.

## 코드 업데이트 방법
앞으로 코드가 바뀌면 `deploy.bat` **하나만** 실행하면 된다(git pull → npm ci → build → 서비스 재시작).
서비스 재시작 단계가 관리자 권한을 요구하므로 `deploy.bat`도 관리자로 실행할 것.

## 재부팅 후 자동 시작 확인 (설치 검증의 핵심)
1. 서버 PC를 실제로 재부팅한다.
2. 로그인하지 말고(또는 로그인 후) 잠시 기다린 뒤:
   - 브라우저에서 `http://localhost:4000` → 로그인 화면이 뜨면 자동 시작 성공.
   - 또는 명령프롬프트에서 `sc query iv-app` → `STATE : 4 RUNNING`.
3. 다른 원내 PC에서 `http://192.168.0.248:4000` 접속도 확인.

## 문제 대응
- 서비스가 안 뜬다 → `C:\iv-app\logs\err.log` 확인.
- 포트 충돌(4000 사용 중) → `netstat -ano | findstr :4000` 로 범인 PID 확인.
- 서비스 완전 제거(재설치 시) → 관리자에서 `"C:\iv-app\tools\nssm.exe" remove iv-app confirm`.
