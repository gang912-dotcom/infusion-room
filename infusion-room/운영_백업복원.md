# 수액실 앱 — 백업 / 복원 운영 안내 (7d)

## 무엇을 백업하나
- 원본: `C:\iv-app\infusion-room\server\data\infusion.db` (환자·세션·라운딩 등 전부)
- 방식: `server/backup.js` 가 `VACUUM INTO` 로 **일관된 단일 스냅샷**을 뜬다.
  (WAL 모드라 단순 파일복사는 위험 → 이 방식으로 누락 방지)
- 목적지: `D:\iv-backup\infusion-YYYY-MM-DD_HHmm.db`
- 보관: **7일**, 그보다 오래된 백업은 자동 삭제
- ⚠️ 외부 클라우드 금지 (환자 실명 포함). D: 드라이브 또는 외장하드/내부망만.

## 수동 백업 (지금 바로 한 번 뜨고 싶을 때)
```bat
C:\iv-app\infusion-room\backup.bat
```
실행 로그: `D:\iv-backup\backup.log` — 마지막 줄 `backup end (exit=0)` 이면 성공.

## 매일 자동 백업 등록 (작업 스케줄러) — 관리자 권한 필요
`admin-setup.bat`을 관리자로 실행하면 자동 등록된다(작업 이름 `IVApp-DB-Backup`, 매일 새벽 3시).
수동으로 등록/재등록하려면 **관리자 권한 명령프롬프트**에서:
```
schtasks /Create /TN "IVApp-DB-Backup" /TR "C:\iv-app\infusion-room\backup.bat" /SC DAILY /ST 03:00 /RU SYSTEM /RL HIGHEST /F
```
- `/RU SYSTEM` : 로그인 안 돼 있어도 실행 (서버라 적합, 로컬 D:만 쓰므로 문제없음)
- 등록 확인: `schtasks /Query /TN "IVApp-DB-Backup"`
- 즉시 테스트 실행: `schtasks /Run /TN "IVApp-DB-Backup"` → `D:\iv-backup` 에 파일이 생기는지 확인

## 복원 절차 (백업으로 되돌리기)
> DB를 통째로 특정 시점으로 되돌리는 작업. **반드시 서버를 먼저 멈춘다.**

1. 서버(수액실 앱) 중지
   - nssm 서비스로 돌고 있으면: 관리자 CMD에서 `nssm stop iv-app`
2. 현재 DB를 혹시 몰라 따로 보관 (덮어쓰기 전 안전장치)
   ```
   cd C:\iv-app\infusion-room\server\data
   ren infusion.db infusion.db.bak-복원전
   del infusion.db-wal infusion.db-shm 2>nul
   ```
   (`-wal`, `-shm` 는 지워도 된다 — 스냅샷 복원 시 불필요)
3. 원하는 백업 파일을 `infusion.db` 라는 이름으로 복사
   ```
   copy "D:\iv-backup\infusion-2026-07-27_0300.db" "C:\iv-app\infusion-room\server\data\infusion.db"
   ```
4. 서버 다시 시작 → `nssm start iv-app`
5. 앱에 로그인해서 데이터가 그 시점 상태인지 눈으로 확인
